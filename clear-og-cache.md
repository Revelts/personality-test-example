# Clear Open Graph Cache

## Method 1: Facebook Sharing Debugger (Best for WhatsApp)
1. Go to: https://developers.facebook.com/tools/debug/
2. Paste your URL
3. Click "Scrape Again" button multiple times (3-5x)
4. This will force refresh WhatsApp cache

## Method 2: Add Query Parameter
Share link with ?v=2 atau ?refresh=1
Example: https://your-domain.com?v=2

## Method 3: Wait
Cache expires after 7-30 days (varies by platform)

## Method 4: Use Different URL
Deploy to new URL/domain for immediate test
